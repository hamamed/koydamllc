Backup & restore

Download backup

What the backup contains

  • Every app, including drafts
  • Privacy Policy, Terms, landing-page copy
  • Company settings and invoicing defaults
  • All invoices and contact enquiries

Not included: uploaded images. Those are files on the server — copy the uploads folder separately if you need them. Download a backup before every deployment.

Restore from a backup

Replaces all current content. The version being replaced is snapshotted first, so a mistaken restore can be undone from the server's backups folder.
